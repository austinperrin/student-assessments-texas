# Runbooks AI Agent Guide

This file guides AI agents working inside `docs/runbooks/`.

## Scope

Use this area for authoritative, task-oriented operating procedures for
recurring human workflows.

## Working Rules

- document commands from the repository root unless explicitly noted
- include prerequisites, side effects, verification, and recovery guidance
- keep complete operator-facing defaults and option descriptions in the owning
  runbook
- make command indexes and implementation READMEs link here instead of copying
  mutable details
- update a runbook in the same change as its human-facing CLI behavior
- keep examples safe, repeatable, and scoped to repository-managed paths
