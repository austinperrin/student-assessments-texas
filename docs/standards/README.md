# Standards

This index routes maintainers to the durable rules that apply across the
repository. Use the nearest assessment-family guidance in addition to these
shared standards.

## Standards By Task

- [Coding standards](./coding-standards.md)
  Mapping shape, normalization, source fidelity, documentation basics, and
  validation expectations.
- [Script standards](./scripts.md)
  Script organization, safety, interfaces, and workflow-documentation
  requirements.
- [Documentation standards](./documentation.md)
  Content ownership, runbook structure, reference direction, and maintenance
  requirements.
- [Commit standards](./commits.md)
  Commit scope, message style, examples, and pre-commit checks.
- [ADR standards](./adr.md)
  When and how to record durable architecture decisions.

## Recommended Reading

- Mapping change: coding standards, then the nearest family `README.md`.
- Script or CLI change: script standards, documentation standards, and the
  owning runbook.
- Documentation restructuring: documentation standards and existing ADRs.
- Commit preparation: commit standards plus the validation required by the
  changed area.

Return to the [Documentation Hub](../index.md) for task-oriented navigation.
