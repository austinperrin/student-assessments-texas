## Findings and resolutions

### TEA-TELPAS-ALT-2022-001: obsolete official source URL

- Severity: low
- State: corrected and verified
- Source evidence: the TEA data-file-formats listing identifies the current 2022 TELPAS Alternate source; the current PDF is the 13-page document described above.
- Finding: `metadata.pdf_url` used a retired TEA path that returned HTTP 404 with HTML on 2026-10-08.
- Correction: replaced it with TEA's current `system/files` PDF URL.
- Verification: the downloaded current official PDF byte-matches the archive at the size and SHA-256 recorded above.
- Historical-data decision: no reprocessing is required because the source document and fixed-width ranges did not change.

### TEA-TELPAS-ALT-2022-002: recurring gifted-and-talented header was not normalized

- Severity: low
- State: corrected and verified
- Source evidence: PDF page 4, position 117, source ordinal 31, `Gifted-Talented-Indicator-Code`; its note states that the student participates in a state-approved Gifted/Talented Program.
- Finding: the mapping used `gifted_talented_indicator_code`.
- Correction: changed the header to the required shared normalization `gifted_and_talented_indicator_code` without changing the source range or meaning.
- Verification: position 117 remains mapped once at source ordinal 31.
- Historical-data decision: consumers using the old header need a schema-name update; byte parsing is unchanged.

### TEA-TELPAS-ALT-2022-003: reporting-category headers omitted the source's score meaning

- Severity: medium
- State: corrected and verified
- Source evidence: PDF page 7, positions 301-304, 501-504, and 701-706, and PDF page 8, positions 753-756. Each of the nine field titles ends in `score`.
- Finding: two listening, two speaking, three reading, and two writing reporting-category headers omitted `_score`, making them less precise than their source titles.
- Correction: added `_score` to all nine headers while retaining the exact source ranges and ordinals.
- Verification: all nine corrected headers are unique, lowercase snake case, at most 63 characters, and remain distinct from raw and scale scores.
- Historical-data decision: consumers using the former nine header names need a schema-name update; fixed-width parsing and values are unchanged.

## Filename provenance and limitations

The layout states on PDF page 2 that delivery is a fixed-length text file with no header, but it does not document a delivered basename. The five existing filename patterns were retained as inherited compatibility patterns. Their references point to external operational guidance or a later TEA naming document and were not used as same-year evidence for 2022 basename syntax. Retention is not a claim that the assigned 2022 layout supports those basename forms.

No 2022 operational sample was available, so delivered basename behavior and parsing against a real file could not be verified. This limitation does not block the source-to-mapping review.
