## Findings And Resolutions

### TCA-2014-001: Omitted named score-code row

- Severity: high
- Source evidence: PDF page 34, positions 1516-1516, length 1, `SCORE CODE`
  in the EOC cumulative-history Biology first-document-submitted section.
- Finding: The named source row was absent. The next mapped row at position
  1517 reused source ordinal 612, and all later ordinals were consequently one
  too low.
- Resolution: Added
  `eoc_cum_hist_bio_first_doc_submitted_score_code` at position 1516 with
  `column_num: "612"`; realigned every subsequent mapping ordinal through the
  final position 2700 row, which is now ordinal 1083.
- Status: corrected; pending independent verification.

### TCA-2014-002: Generated hash-suffixed headers

- Severity: medium
- Source evidence: field labels throughout PDF pages 9-60, including Level II
  standards, Level III performance, progress measures, scale scores,
  accommodations, cumulative-history fields, and TELPAS comprehension scores.
- Finding: 98 headers ended in opaque generated hexadecimal suffixes and, in
  several cases, truncated the distinguishing source concept.
- Resolution: Replaced all 98 with unique source-supported section-qualified
  names at or below 63 characters. No range or meaning was collapsed across
  assessment, subject, administration, or historical sections.
- Status: corrected; pending independent verification.

### TCA-2014-003: Outdated official URL path

- Severity: low
- Source evidence: the TEA data-file-formats archive links the 2014
  consolidated layout at the current `/data-reports/student-assessment-results/`
  path.
- Finding: `metadata.pdf_url` used the retired
  `/student-assessment/student-assessment-results/` path, which returned HTTP
  404 during review.
- Resolution: Updated metadata to the verified current official URL. The
  downloaded official PDF byte-matches the archived source.
- Status: corrected; pending independent verification.

### TCA-2014-004: Printed enrolled-grade endpoint inconsistency

- Severity: low
- Source evidence: PDF page 59 prints positions `2497-2798`, length 2, for
  `ENROLLED GRADE`; the following blank begins at 2499 and the section ends at 2505.
- Finding: The printed end position conflicts with the stated length and the
  next row.
- Resolution: Retained positions 2497-2498. This is the only interpretation
  consistent with the row's length, adjacent coverage, and the 2700-character
  record. No ordinal change was required for this source typo.
- Status: resolved; pending independent verification.
