## Findings And Resolutions

### TEA-STAAR-CAF-2023-001: Restore source-row ordinals

- Severity: high
- Source fact: the layout contains 833 ordered rows, including 93 blank rows.
- Initial implementation: `column_num` was a contiguous mapped-field counter,
  so it did not preserve source ordinal gaps after omitted blanks.
- Correction: all 740 mapped fields now use their actual source-row ordinal.
- Final status: corrected and verified by Reviewer 1

### TEA-STAAR-CAF-2023-002: Map every named row and omit every blank row

- Severity: high
- Source fact: 740 rows are named fields and 93 rows are explicitly `Blank`.
- Initial implementation: 83 named rows were omitted, including Approaches
  Grade Level at Student's Standard, HSEP, cumulative-history indicators, test
  form fields, and other repeated assessment fields.
- Correction: added all 83 omitted named rows. The source overview and page 38
  both identify positions 2150-2151 as Writing Tested Grade; that named row is
  retained, while the actual blank at positions 2152-2154 is omitted.
- Final status: corrected and verified by Reviewer 1

### TEA-STAAR-CAF-2023-003: Correct source terminology in headers

- Severity: medium
- Source fact: positions 359-388, 1453-1517, and 1635-1676 are English II
  sections; positions 1692-1724 are 2023 Reading Language Arts; and the source
  provides meaningful titles for administration, record-update, PEIMS, and
  TELPAS fields.
- Initial implementation: those English II blocks were labeled as English I,
  the 2023 RLA block was labeled only as reading, and ten headers ended in
  opaque generated hashes rather than preserving the source meaning.
- Correction: corrected the English II and RLA sections and replaced opaque
  headers with concise source-supported names while retaining uniqueness and
  the 63-character limit.
- Final status: corrected and verified by Reviewer 1

### TEA-STAAR-CAF-2023-004: Replace obsolete official URL

- Severity: medium
- Source fact: the initial metadata URL returns 404; TEA currently indexes the
  2022-23 CAF layout at the URL recorded above.
- Correction: updated `metadata.pdf_url` to TEA's current official URL.
- Final status: corrected and verified by Reviewer 1

### TEA-STAAR-CAF-2023-005: Restore Accommodation(s) Used at position 319

- Severity: high
- Source fact: page 9 identifies position 319 as the named one-position field
  `Accommodation(s) Used`; its length cell is blank, but its start and end are
  both 319. The following row is blank at positions 320-324.
- Reviewer 2 finding: the named position-319 row was absent, causing every
  subsequent mapped and omitted source ordinal to be one too low.
- Correction: added `accommodations_used` at position 319 with
  `column_num: "103"` and incremented every later source ordinal. Position 325
  is now ordinal 105 and the final field at position 2206 is ordinal 833.
- Final status: corrected and verified by Reviewer 1; pending Reviewer 2 final
  confirmation
