## Findings And Resolutions

### CA2015-01: Generated hash suffixes obscured source-supported headers

- Severity: medium
- Status: corrected
- Evidence: 63 mapped headers ended in six-character hexadecimal suffixes,
  including source rows on pages 22-61. The PDF provides the row meaning and
  surrounding program, administration, subject, and history context needed for
  concise unique names.
- Resolution: Replaced all 63 generated headers with lowercase snake-case names
  that retain the source-supported section and field meaning and remain at or
  below 63 characters. No ranges or ordinals changed.

### CA2015-02: Metadata cited a retired TEA path

- Severity: low
- Status: corrected
- Evidence: The inherited `/student-assessment/student-assessment-results/`
  URL returns HTTP 404. The equivalent current `/data-reports/` URL downloads a
  PDF with the same SHA-256 as the archived source.
- Resolution: Updated `metadata.pdf_url` to the verified current TEA URL.

### CA2015-03: Printed end position conflicts with length and sequence

- Severity: source-document note
- Status: resolved
- Evidence: PDF page 56 prints `2497-2798`, length 2, for `ENROLLED GRADE`.
  The following blank row begins at 2499, so the internally consistent range is
  2497-2498.
- Resolution: Retained the existing mapping at positions 2497-2498 and ordinal 958. This is a source typo interpretation, not a mapping correction.
