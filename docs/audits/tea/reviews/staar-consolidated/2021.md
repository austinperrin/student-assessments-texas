## Findings And Corrections

### Opaque Generated Header Suffixes

- State: corrected
- Severity: medium
- Evidence: the named rows on source pages 7, 9–26, 34–35, 40–49, and 52,
  including positions 163, 201–205, 440, 456–460, 485, 555, 625, 695,
  711–715, 896–899, 924, 974, 999, 1074, 1081–1084, 1159, 1184, 1259,
  1266–1269, 1296, 1321, 1346, 1396, 1444, 1446, 1704–1707, 1735,
  1746–1788, 1901, 1971, 2006, 2056–2060, 2325, 2327, and 2512.
- Finding: 54 headers ended in opaque six-character generated hashes. Several
  truncated the source field name entirely, including administration-date and
  record-update-indicator rows. The hashes were not source terminology and made
  the affected schema keys difficult to interpret.
- Correction: replaced all 54 generated names with concise source-supported
  snake-case names. The new names preserve the administration, subject,
  current/previous-year, cumulative-history, and submitted/scored distinctions
  necessary to keep repeated source labels unique.
- Affected source ordinals: 58, 66, 67, 144, 153, 154, 163, 196, 213, 231,
  240, 241, 328, 336, 358, 369, 380, 385, 415, 426, 437, 442, 452, 463,
  474, 485, 494, 496, 602, 610, 616–619, 621–624, 626–629, 631–634, 690,
  729, 747, 773, 774, 884, 886, and 956.
- Resolution: corrected in the year mapping. All corrected headers are unique,
  lowercase snake case, meaningful, and no longer than 63 characters.

No source-supported position, length, ordinal, row-presence, metadata, or code
correction was required.
