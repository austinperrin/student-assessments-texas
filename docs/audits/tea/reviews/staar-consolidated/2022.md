## Findings And Resolutions

### TEA-STAAR-CAF-2022-001: Restore source-row ordinals

- Severity: high
- Source fact: the layout contains 810 ordered rows, including 93 blank rows.
- Initial implementation: `column_num` stopped at 727 because it acted as a
  mostly contiguous mapped-field counter rather than the source-row ordinal.
- Correction: all 717 mapped rows now carry their actual source ordinal,
  including gaps for every omitted blank. Position 2206 is ordinal 810.
- Final status: corrected and verified by Reviewer 1

### TEA-STAAR-CAF-2022-002: Restore every omitted named row

- Severity: high
- Source fact: 717 source rows are named fields and 93 are explicitly blank.
- Initial implementation: 83 named rows were absent, including Approaches
  Grade Level, High School Equivalency Program, test-form, EOC cumulative
  history, and repeated grades 3-8 fields.
- Correction: added all 83 named rows. This includes page 7 position 319,
  `Accommodation(s) Used`, whose printed length cell is empty but whose start
  and end positions both establish length 1.
- Final status: corrected and verified by Reviewer 1

### TEA-STAAR-CAF-2022-003: Preserve English I and English II boundaries

- Severity: high
- Source fact: the layout separately labels English I and English II blocks
  in each EOC administration and in EOC cumulative history.
- Initial implementation: English II rows were represented as later suffixed
  English I headers.
- Correction: renamed all English II block headers to `english_2`/`eng_2`,
  retained English I as `english_1`/`eng_1`, and assigned stable within-subject
  suffixes for repeated administrations.
- Final status: corrected and verified by Reviewer 1

### TEA-STAAR-CAF-2022-004: Remove generated header debris

- Severity: medium
- Source fact: the affected rows have explicit field titles, including
  Administration Date, Record Update Indicator, Unaccompanied Youth Status
  Code, and Students with Interrupted Formal Education.
- Initial implementation: ten headers ended with opaque generated hexadecimal
  fragments, obscuring their source meaning.
- Correction: replaced the opaque headers with concise source-supported names
  and retained unique headers within the 63-character limit.
- Final status: corrected and verified by Reviewer 1

### TEA-STAAR-CAF-2022-005: Resolve the printed 728-279 range typo

- Severity: medium
- Source fact: page 15 prints Enrolled Grade as start 728, end 279, length 2;
  the following Test Version begins at 730.
- Interpretation and correction: retained the mapping range 728-729 because
  it is the only range consistent with the printed start, length, and next row.
- Final status: verified by Reviewer 1; no mapping-range change required

### TEA-STAAR-CAF-2022-006: Use the current official URL

- Severity: medium
- Source fact: TEA's current Data File Formats page links the source under the
  `/data-reports/student-assessment-results/` path; the old metadata URL
  returns 404.
- Correction: updated `metadata.pdf_url`. The retrieved official PDF and
  same-year repository archive have identical SHA-256 hashes.
- Final status: corrected and verified by Reviewer 1
