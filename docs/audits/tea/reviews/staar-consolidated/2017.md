## Findings And Resolutions

### SC-2017-001: Five named source rows were omitted

- Severity: high
- Status: corrected
- Evidence: source pages 37-39 identify named fields at position 1908
  (`ABOVE GRADE`), positions 1912 and 1913 (`ELL PROGRESS MEASURE` and
  `ACCOMMODATION(S) USED`), and positions 1964 and 1965 (`SCORE CODE` and
  `SCORE CODE DEFAULT`). These rows were absent from `mapped_fields`.
- Resolution: added all five fields and recalculated every `column_num` from
  the complete 995-row source sequence. Position 1909 is now ordinal 706,
  position 1916 is ordinal 711, position 1967 is ordinal 737, and position
  2700 is ordinal 995.

### SC-2017-002: Generated header debris obscured source meaning

- Severity: medium
- Status: corrected
- Evidence: 40 headers contained generated hash suffixes or explicit
  placeholder text, including administration dates, record-update indicators,
  performance results, cumulative-history fields, and the position-2425
  performance field. The affected source sections appear on pages 6-47.
- Resolution: replaced the opaque fragments with concise source-supported
  terminology while retaining program, administration, subject, and history
  distinctions. All resulting headers are unique lowercase snake case and no
  longer than 63 characters.
