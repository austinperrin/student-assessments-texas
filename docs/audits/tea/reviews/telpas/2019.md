## Findings And Corrections

### Position 243 named row and downstream source ordinals

- Source evidence: PDF page 7 (numbered page 6), positions 241–243, followed by blank positions 244–260; PDF pages 8–13 for the subsequent ordinal sequence.
- Finding: `Extra Day` at position 243 is a named one-position reading-accommodation row but was absent from the mapping. The next mapped row at position 261 used ordinal 68 instead of source ordinal 70, and all later mapped ordinals remained two low through the final row.
- Correction: added `reading_extra_day` at position 243 with `column_num: "68"`; retained blank 244–260 as omitted source ordinal 69; increased every mapped ordinal from position 261 onward by two. Position 261 is now ordinal 70 and position 1200 is ordinal 137.
- Resolution: corrected and structurally reconciled.

### Official source metadata

- Source evidence: TEA's current Data File Formats Archive, 2019 TELPAS link.

### Filename evidence

- Source evidence: PDF page 2 (numbered page 1) states that delivery is a fixed-length text file and that the file extension is `.txt`; it does not document delivered basenames.
- Finding: all four inherited filename regexes allowed the documented `.txt` extension to be omitted.
- Correction: made `.txt` mandatory in every inherited regex.
- Provenance limitation: the same-year source does not establish the inherited `SF`, `PF`, `SDR`, grade, district, version, or timestamp basename forms. Those components were retained rather than inferred or replaced because the 2019 evidence does not contradict them.
- Resolution: extension behavior corrected; basename provenance limitation retained.
