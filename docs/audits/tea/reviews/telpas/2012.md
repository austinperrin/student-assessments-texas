## Findings and resolutions

### Corrected: omitted named rows

- Page 12, positions 624-626, ordinal 105: added `telpas_comprehension_score`.
- Page 12, position 630, ordinal 107: added `telpas_composite_rating`.
- Page 12, positions 627-629: clarified `telpas_composite` to `telpas_composite_score` so score and rating remain distinct.

### Corrected: history block year and assessment meaning

Pages 13-14 identify distinct Spring 2004 through Spring 2011 history groups. The prior mapping labeled the groups beginning at position 651 as 2007 and ending at position 753 with position-derived placeholders. Reviewer 1 realigned every history header to its source group:

- 2004 at positions 651-663, including TELPAS Reading Rating and Score Code.
- 2005-2007 at positions 664-717, preserving the source's RPTE scale score, proficiency rating, and score code terminology.
- 2008-2011 at positions 718-789, preserving TELPAS composite and TELPAS Reading terminology.
- Added the previously omitted named 2010 rows at positions 754-771 and 2011 rows at positions 772-789.
- Preserved the documented blank at positions 790-799 and corrected `period` to ordinal 157.

### Corrected: source and OCR artifacts in headers

- Page 6: corrected `HEADER AGENCY USE`, Fall 2011 PEIMS county-district-campus number, and Fall 2011 PEIMS crisis code; removed unsupported position and `TSDS` artifacts.
- Pages 7-9: removed answer-column suffixes from Type 1/2/3 Accommodations and replaced position-derived rating defaults with the documented Listening, Speaking, Writing, and Reading Score Code Default names.
- Page 5: retained the grades 6-12 scope in the career-and-technical header while removing the answer-document `CT` spillover.
- Page 5: normalized Gifted/Talented to `gifted_and_talented_indicator_code`, supported by the source meaning and shared naming rule.
- Page 10: replaced position-derived duplicate disambiguators with proficiency-level-qualified reporting-category headers.

All findings above are `corrected` and were verified against the cited source pages and positions.

## Limitations

- No operational 2012 data samples were available, so value-level parsing and delivered basename behavior could not be tested.
- The current TEA site did not provide a downloadable file at the recorded official URL during this review, preventing a live-source/archive byte comparison.
- The 2012 layout does not state delivered filenames. Inherited filename regexes remain present, but this review does not claim same-year basename provenance for them.
- Only the 2012 mapping, the 2012 TELPAS source archive, and governing repository instructions were used as audit evidence. No other year's mapping or source informed a conclusion.

## Historical-data decision

The fixed-width positions and raw record width did not change. Consumers that generated schemas from the old mapping should refresh the 2012 schema and reprocess 2012 files if they need the newly mapped comprehension/composite-rating fields, accurate history-year labels, or the corrected field names. Existing raw files do not require transformation.
