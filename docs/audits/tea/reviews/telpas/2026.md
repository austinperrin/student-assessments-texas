## Findings And Corrections

### Current official layout superseded the archived row boundary

- Finding: The prior archive and mapping ended `Reading Points Possible by
Item` at position 688 and began the following blank at 689. The current
  official page 11 table defines the named row as positions 651-687, length 37,
  and the blank as positions 688-700, length 13.
- Correction: Replaced the archived layout with the current official bytes and
  changed the mapped named range to 651-687. The blank remains omitted. Source
  ordinal 124 and all later ordinals remain unchanged.
- Resolution: corrected and ready for independent verification.

### Shared gifted-and-talented normalization was missing

- Finding: The page 4 source title `Gifted-Talented-Indicator-Code` at position
  117 has the repository's shared gifted-and-talented meaning, but the mapping
  used `gifted_talented_indicator_code`.
- Correction: Renamed the header to
  `gifted_and_talented_indicator_code` without changing its range or source
  ordinal 32.
- Resolution: corrected and ready for independent verification.

### Metadata and same-year filename evidence required alignment

- Finding: `metadata.pdf_url` and the naming-PDF reference used TEA's former
  `/student-assessment/student-assessment-results/` path. The current official
  documents resolve under `/data-reports/student-assessment-results/`.
- Correction: Updated both URLs. The same-year naming PDF documents Spring 2026
  TELPAS administration code `0326`, preliminary/final `SP`/`SF` prefixes, and
  `.txt` reporting data files. The matching regex was narrowed to `0326` and a
  required `.txt` suffix instead of also accepting unsupported `2026` and an
  absent extension.
- Resolution: corrected and ready for independent verification.

  as row-mapping evidence in this isolated audit.
