## Findings and resolutions

### F-2014-01 — omitted score-code rows and shifted labels

- Severity: high
- Source: pages 8–9, positions 231, 232, 246, 247, 261, 262, 276, and 277
- Finding: the named Listening, Speaking, Writing, and Reading Score Code rows were omitted. Each following Score Code Default row was mislabeled as the score code.
- Resolution: added all four score-code rows and renamed the four default rows. Reconciled every downstream source ordinal.
- State: `verified`

### F-2014-02 — source ordinals did not represent the complete layout

- Severity: high
- Source: pages 8–13, positions 231–800
- Finding: downstream `column_num` values did not account for the four omitted named rows. Positions 623–637 were also out of positional/source order, and the blank row at positions 651–663 was not represented as an ordinal gap.
- Resolution: recalculated ordinals against all 145 named and blank source rows. Positions 553–622 are ordinal 105; positions 623–637 are ordinals 106–111; history begins at ordinal 114; and position 800 is ordinal 145.
- State: `verified`

### F-2014-03 — headers lost or added source meaning

- Severity: medium
- Source: pages 5–7 and 10, positions 117, 135–137, 141, 155–163, 174–175, and 291–323
- Finding: headers omitted the source's `and`, column letters, grades 1–12 scope, Fall 2013 PEIMS context, or proficiency-level section context. The crisis-code header also added unsupported `TSDS` and a numeric suffix.
- Resolution: corrected those headers directly from the 2014 source. Shared normalization was applied only where the same source meaning independently supports it.
- State: `verified`

### F-2014-04 — official source URL moved

- Severity: medium
- Source: official TEA location and identical archived document
- Finding: `metadata.pdf_url` used the retired `/student-assessment/student-assessment-results/` path, which returned HTTP 404 on 2026-10-07.
- Resolution: updated it to the current official `/data-reports/student-assessment-results/` URL and confirmed byte identity with the archive.
- State: `verified`
