## Filename provenance and limitations

The 2024–2025 TTAP layout describes a fixed-width district data file but does not prescribe a delivered basename. No separate same-year naming document for TTAP and no operational sample or delivered filename were available. Therefore the mapping does not add `filename_patterns`; a regex would be unsupported by the available same-year evidence.

The audit validates the documented layout only. It does not validate an operational file instance because none was available.
