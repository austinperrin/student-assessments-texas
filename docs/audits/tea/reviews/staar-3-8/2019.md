### TEA-STAAR38-2019-001: Column numbers do not preserve source ordering

- Status: confirmed
- Severity: medium
- Reviewer: Codex
- Verifier: not required
- Disposition owner: Austin Perrin
- Target date: before family audit closure
- Source document: 2019 STAAR Grades 3-8 Data File Format
- Source page/table: pages 3-34, complete fixed-width layout
- Source positions/columns: ordered source rows, including blank ranges
- Current mapping positions: all 432 mapped fields

#### Source fact

Repository rules require `column_num` to preserve source-row ordering and gaps
caused by omitted blank rows.

#### Current implementation and impact

The mapping numbers every mapped field continuously from 1 through 432, so the
values cannot reliably trace fields to their source rows.

#### Proposed disposition

Recalculate source-row ordinals during remediation.

### TEA-STAAR38-2019-002: Mapping references use a retired layout path and non-year-matched filename evidence

- Status: confirmed
- Severity: medium
- Reviewer: Codex
- Verifier: not required
- Disposition owner: Austin Perrin
- Target date: before family audit closure
- Source document: 2019 layout and mapping filename references
- Source positions/columns: not applicable
- Current mapping positions: `metadata[0].pdf_url` and `filename_patterns`

#### Source fact

TEA's current `/data-reports/` copy matches the archive byte-for-byte. The
mapping's older `/student-assessment/` URL returns HTTP 404, and no year-matched
filename convention is cited.

#### Current implementation and impact

Seven patterns cite a current SDR guide and one general pattern cites the
2025-2026 naming document while accepting 2019 forms. Layout content is
recoverable, but the stored URL and filename provenance are not current or
year-matched.

#### Proposed disposition

Update the mapping to the current official layout URL and retain filename forms
only when supported by 2019 evidence.

### TEA-STAAR38-2019-003: Headers require year-specific normalization fixes

- Status: confirmed
- Severity: low
- Reviewer: Codex
- Verifier: not required
- Disposition owner: Austin Perrin
- Target date: before family audit closure
- Source document: 2019 STAAR Grades 3-8 Data File Format
- Source page/table: accommodation and history sections
- Source positions/columns: recurring concepts, including 2251-2840
- Current mapping positions: abbreviated `cy_*` and `py_*` headers

#### Source fact

The cited fields use full subject and administration concepts, and several
accommodation fields explicitly include refreshable Braille and screen reader.

#### Current implementation and impact

Many history headers use opaque abbreviations and recurring concepts do not
consistently follow the family normalization rules. Positions remain accurate,
but names are harder to trace across years.

#### Proposed disposition

Apply source-faithful canonical names after downstream consumer review.
