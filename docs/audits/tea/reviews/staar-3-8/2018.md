### TEA-STAAR38-2018-001: Five source fields are omitted

- Status: confirmed
- Severity: high
- Reviewer: Codex
- Verifier: Austin Perrin
- Disposition owner: Austin Perrin
- Target date: before audit closure
- Source document: 2018 STAAR Grades 3-8 Data File Format
- Source page/table: pages 5, 6, and 29
- Source positions/columns: 107, 122, 132-140, 143, and 2676
- Current mapping positions: absent

#### Source fact

The source defines `LEP-INDICATOR-CODE` at 107,
`CAREER-AND-TECHNICAL-ED-INDICATOR-CODE` at 122, `DOCUMENT NUMBER` at
132-140, `RECORD UPDATE INDICATOR` at 143, and previous-year mathematics
spring `Meets Grade Level` at 2676. None of these fields is mapped.

#### Proposed disposition

Add all five fields with source-faithful headers and positions.

### TEA-STAAR38-2018-002: Twenty-one mappings occupy source-declared blank ranges

- Status: confirmed
- Severity: high
- Reviewer: Codex
- Verifier: Austin Perrin
- Disposition owner: Austin Perrin
- Target date: before audit closure
- Source document: 2018 STAAR Grades 3-8 Data File Format
- Source page/table: pages 6, 8-10, 28, and 29
- Source positions/columns: 165-185, selected 255-343 accommodation bytes, 2646-2650, 2706-2710, and 2736-2740
- Current mapping positions: 21 mapped fields

#### Source fact

The source marks all affected bytes as `BLANK`. This includes positions
165-189; unused accommodation bytes at 255, 263-271, 275, 277-278, 283-291,
296, 298-299, 315, 323-331, 335, 337-338, and 343-350; and the three
previous-year mathematics ranges 2646-2650, 2706-2710, and 2736-2740.

#### Current implementation and impact

The mapping assigns these bytes to foster care, class group, oral
administration, calculator, ASL video, auto text-to-speech, and Quantile
fields. Unexpected filler could therefore be reported under concepts the 2018
source does not define.

#### Proposed disposition

Remove the 21 mappings that fall wholly within documented blank ranges.

### TEA-STAAR38-2018-003: Positions 2676-2680 combine a result field with blank bytes

- Status: confirmed
- Severity: high
- Reviewer: Codex
- Verifier: Austin Perrin
- Disposition owner: Austin Perrin
- Target date: before audit closure
- Source document: 2018 STAAR Grades 3-8 Data File Format
- Source page/table: page 29, previous-year mathematics spring administration
- Source positions/columns: 2676-2680
- Current mapping positions: `py_math_spring_admin_quantile_measure`

#### Source fact

Position 2676 is `Meets Grade Level`; positions 2677-2680 are `BLANK`.

#### Current implementation and impact

The mapping treats all five bytes as a previous-year spring Quantile measure,
suppressing the documented result and assigning it the wrong meaning.

#### Proposed disposition

Map the one-byte Meets Grade Level field at 2676 and omit 2677-2680.

### TEA-STAAR38-2018-004: Most mapped fields omit column numbers

- Status: confirmed
- Severity: medium
- Reviewer: Codex
- Verifier: not required
- Disposition owner: Austin Perrin
- Target date: before family audit closure
- Source document: 2018 STAAR Grades 3-8 Data File Format
- Source page/table: pages 3-31
- Source positions/columns: all ordered source rows
- Current mapping positions: 235 of 413 mapped fields

#### Source fact

Every mapped field must contain a string `column_num` preserving source-row
ordering and gaps caused by omitted blank rows.

#### Current implementation and impact

Two hundred thirty-five fields have no `column_num`; the remaining values do
not consistently preserve source-row ordinals.

#### Proposed disposition

Recalculate and populate all source-row ordinals after field remediation.
