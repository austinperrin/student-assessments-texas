200 and the same PDF bytes as the repository archive.

returned HTTP 404 with HTML content instead of a PDF.

#### Impact

current official file. Maintainers and automated consumers cannot retrieve the
governing source through the stored metadata URL.

source review, then correct `metadata[0].pdf_url` on a separate remediation
branch. No historical data reprocessing appears necessary because this affects
source provenance metadata rather than fixed-width positions or parser logic.
