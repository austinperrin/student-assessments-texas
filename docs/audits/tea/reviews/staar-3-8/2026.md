### TEA-STAAR38-2026-002: Previous-year RLA headers are inconsistently normalized

- Status: confirmed
- Severity: low
- Reviewer: Codex
- Verifier: Austin Perrin
- Disposition owner: Austin Perrin
- Target date: before STAAR grades 3-8 family audit closure
- Next review date: not applicable
- Disposition reason: normalize the twelve affected headers on a separate remediation branch
- Accepted by and acceptance date: Austin Perrin, 2026-09-25
- Mapping:
  [2026 STAAR 3-8 mapping](../../../../../assessments/tea/staar/3_8/2026-staar-3-8-fixed-width-mapping.json)
- Source document: 2026 STAAR Grades 3-8 Data File Layout
- Official URL:
  `https://tea.texas.gov/data-reports/student-assessment-results/2026-staar-3-8-data-file-layout-final-tagged.pdf`
- Source page/table: pages 17-19, Previous Year Reading Language Arts History
  and Previous Year History Additional Data
- Source positions/columns: 2531-2560 and 2840
- Current mapping positions: mapped fields 264-275 and 314

#### Source fact

Pages 17-19 group positions 2531-2560 under `Previous Year Reading Language
Arts History`. Position 2840 is `Meets Grade Level - Reading Language Arts`
under `Previous Year History Additional Data`. Visual inspection confirms the
table grouping and titles where the tagged text wraps across lines.

#### Current implementation

Seven fields in positions 2531-2560 use the abbreviated prefix
`py_rla_language_arts_`, and four use the duplicated prefix
`previous_year_reading_language_arts_language_arts_`. Position 2840 is an
eighth field using the abbreviated form, for twelve affected fields in total.
Other subjects in the same section use full `previous_year_<subject>_*` names,
and the family guidance requires
`previous_year_reading_language_arts_*` for previous-year RLA history fields.

#### Impact

The positions and lengths remain accurate. The inconsistent names make the
mapping harder to use and violate the family's normalization rule, but they do
not alter source values.

#### Proposed disposition

Normalize the twelve headers to the
`previous_year_reading_language_arts_*` namespace on a separate
remediation branch. Evaluate downstream consumers before renaming because
column-header changes can affect imports even when byte ranges do not change.

#### Verification

Independent verification is not required for this low-severity finding. The
reviewer confirmed all twelve affected fields against rendered pages 17-19.

#### Resolution

- Remediation issue/PR: pending
- Correcting commit: pending
- Validation: pending
- Historical-data decision: deferred until remediation reviews consumers of
  the twelve column headers

### TEA-STAAR38-2026-004: Filename patterns accept unsupported 2026 forms

- Status: confirmed
- Severity: medium
- Reviewer: Codex
- Verifier: Austin Perrin
- Disposition owner: Austin Perrin
- Target date: before STAAR grades 3-8 family audit closure
- Next review date: not applicable
- Disposition reason: restrict or remove unsupported patterns on a separate remediation branch
- Accepted by and acceptance date: Austin Perrin, 2026-09-25
- Mapping:
  [2026 STAAR 3-8 mapping](../../../../../assessments/tea/staar/3_8/2026-staar-3-8-fixed-width-mapping.json)
- Source documents: 2025-2026 Naming Conventions for Reports and Files and
  Student Data Request (SDR) User Guide
- Official URLs:
  `https://tea.texas.gov/data-reports/student-assessment-results/2025-2026-file-naming-convention.pdf`
  and
  `https://txassessmentdocs.atlassian.net/wiki/spaces/ODCCM/pages/4146626561/Student+Data+Request+SDR+User+Guide`
- Source page/table: naming conventions pages 2 and 8; SDR guide, Historical
  Scoring Reports Returned and Sample STAAR 3-8 File Naming Conventions
- Source positions/columns: not applicable
- Current mapping positions: `filename_patterns[0]` through
  `filename_patterns[3]`, and `filename_patterns[5]`

#### Source fact

The 2025-2026 naming document assigns season `0526` to Spring 2026 STAAR grades
3-8 and documents `SP_SeasonYY_3-8_...` and `SF_SeasonYY_3-8_...` reporting
files. The SDR guide describes historical files in their original layouts,
states that STAAR grades 3-8 history is available only through 2025, and lists
the `03YY`, `04YY`, `15YY`, `05YY`, and `06YY` forms as historical examples.

#### Current implementation

The first four regexes substitute `26` into historical SDR forms even though
the cited guide excludes 2026 historical records. The sixth regex accepts
seasons `1526` and `0626` and the assessment token `3_8`, while the current
official naming document supports `0526` and `3-8` for this family. All six
regexes compile successfully.

#### Impact

Filename-based routing can classify files as compatible with the 2026 layout
without cited evidence that those forms represent 2026 STAAR grades 3-8 data.
No suitable operational sample was available to quantify false matches.

#### Proposed disposition

On a separate remediation branch, remove or narrow the unsupported patterns
and retain only forms supported by current official documentation or separately
recorded operational evidence. Review consumers before changing routing rules.

#### Verification

Independent verification is not required for this medium-severity finding. The
reviewer compared every regex with its cited source and the administration code
in the 2026 layout.

#### Resolution

- Remediation issue/PR: pending
- Correcting commit: pending
- Validation: pending
- Historical-data decision: reprocessing is deferred until remediation
  determines whether any files were selected through unsupported forms

## Reviewed With No Findings

The archived source and current online PDF were compared byte-for-byte. They
have the same size and SHA-256 digest.

All 376 source rows were extracted in source order. The mapping contains all
300 nonblank ranges, omits all 76 blank ranges, and has no extra or overlapping
ranges. Every mapped `column_num` matches its source-row ordinal. All start and
end positions imply the source field lengths. Tagged-text extraction was used
for the complete range comparison, and ambiguous wrapped titles were checked
against rendered pages.

All source titles, acceptable values, notes, and section-level administration
behavior were reviewed for semantic qualifiers affecting the mapping. Except
for findings 002, 003, and 005, the normalized headers preserve the source
meaning. JSON shape and string values are valid; headers are unique and no
header exceeds 63 characters. All six filename regexes compile; the unsupported
forms are recorded in finding 004. The `0526` administration metadata agrees
with the source.
