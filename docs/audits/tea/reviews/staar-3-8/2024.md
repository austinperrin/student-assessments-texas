### TEA-STAAR38-2024-001: Science fields reflect the 2026 layout instead of the 2024 source

- Status: candidate
- Severity: high
- Reviewer: Codex
- Verifier: Austin Perrin (pending)
- Disposition owner: unassigned pending verification
- Target date: before STAAR grades 3-8 family audit closure
- Next review date: not applicable
- Disposition reason: restore the omitted fields and correct the item-field concept separately
- Accepted by and acceptance date: pending
- Mapping:
  [2024 STAAR 3-8 mapping](../../../../../assessments/tea/staar/3_8/2024-staar-3-8-fixed-width-mapping.json)
- Source document: 2024 STAAR Grades 3-8 Data File Layout
- Official URL:
  `https://tea.texas.gov/data-reports/student-assessment-results/2024-staar-3-8-data-file-format.pdf`
- Source page/table: pages 16-17, Science Subject Information and Science Item
  Level Information
- Source positions/columns: positions 1901-1908, source rows 249-252; positions
  2001-2038, source row 266
- Current mapping positions: omitted ranges before mapped field 196; mapped
  field 206

#### Source fact

Rendered page 16 defines four two-character fields at positions 1901-1908:
Science Reporting Category 1-4 Score. Rendered page 17 defines positions
2001-2038 as `Item Reporting Category Numbers - Science`, with values 1-4
representing reporting categories. The 2024 overview separately states that
the reporting-category score fields are replaced with blanks in 2026, not in 2024.

#### Current implementation

The mapping has no fields for positions 1901-1908. It maps positions 2001-2038
as `item_strand_numbers_science`, the concept introduced by the 2026 layout.

#### Impact

An import using this mapping discards all four science reporting-category
scores and labels 38 science item values as strands rather than reporting
categories. Without an operational sample, affected-record counts are unknown.

#### Proposed disposition

Add the four missing fields and rename the item field on a separate remediation
branch. Review downstream schemas and any 2024 imports to decide whether
reprocessing is required.

#### Verification

Pending independent comparison of PDF pages 16-17 with mapping positions
1901-1908 and 2001-2038.

#### Resolution

- Remediation issue/PR: pending
- Correcting commit: pending
- Validation: pending
- Historical-data decision: unknown; operational history and consumer impact
  require review

- Source document: 2024 STAAR Grades 3-8 Data File Layout
- Official URL:
  `https://tea.texas.gov/data-reports/student-assessment-results/2024-staar-3-8-data-file-format.pdf`
- Source page/table: pages 3-22, complete fixed-width layout
- Source positions/columns: source rows 14-392 where nonblank
- Current mapping positions: 296 mapped fields beginning at mapped field 13

#### Source fact

The source contains 392 ordered layout rows, including 76 blank ranges. Shared
mapping rules require `column_num` to preserve those row ordinals, including
gaps where blank fields are omitted.

#### Current implementation

All 308 mapped fields use a continuous `column_num` sequence from 1 through 308. The first blank source row is row 13, and 296 mapped fields have a
`column_num` that differs from their source-row ordinal. Eight omitted nonblank
fields create additional offsets later in the file.

#### Impact

Byte ranges remain authoritative, but consumers and reviewers cannot use
`column_num` to trace fields to source rows as the repository contract intends.

#### Proposed disposition

Recalculate `column_num` from the 392 source rows on a separate remediation
branch after finding 001 is resolved.

#### Verification

Independent verification is not required for this medium-severity finding. An
ordered comparison reproduced 296 mismatches and confirmed that the current
numbers are the sequential mapped-field ordinals.

#### Resolution

- Remediation issue/PR: pending
- Correcting commit: pending
- Validation: pending
- Historical-data decision: reprocessing is unnecessary unless a downstream
  consumer uses `column_num` as data rather than documentation
