### TEA-STAAR38-2021-001: Writing accommodations and results are omitted

- Status: confirmed
- Severity: high
- Reviewer: Codex
- Verifier: Austin Perrin
- Disposition owner: Austin Perrin
- Target date: before family audit closure
- Source document: 2021 STAAR Grades 3-8 Data File Format
- Official URL: `https://tea.texas.gov/student-assessment/student-assessment-results/2021-staar-3-8-data-file-format.pdf`
- Source page/table: pages 10-11 and 20-23, Writing accommodations and subject information
- Source positions/columns: 292-301 and 1101-1313
- Current mapping positions: omitted between mapped fields 88-89 and 169-172

#### Source fact

Positions 292-301 define ten Writing accommodation fields. Positions
1101-1313 define Writing scores, administration details, the new Writing Test
Form Version, grade-level indicators, written composition score, EL performance
measure, three item-level ranges, and percentile.

#### Current implementation

All named Writing fields are absent. Two unrelated mapped ranges at 1103-1147
and 1148-1192 occupy part of the Writing section.

#### Impact

The mapping cannot expose Writing accommodations or results and assigns some
Writing bytes to unrelated concepts.

#### Proposed disposition

Restore the complete source-defined Writing structure after independent
verification and assess historical reprocessing.

#### Verification

Austin Perrin independently reviewed and confirmed the omitted Writing fields
and conflicting mapped ranges on 2026-09-25.

### TEA-STAAR38-2021-002: Twelve item-level ranges disagree with the source

- Status: confirmed
- Severity: high
- Reviewer: Codex
- Verifier: Austin Perrin
- Disposition owner: Austin Perrin
- Target date: before family audit closure
- Source document: 2021 STAAR Grades 3-8 Data File Format
- Source page/table: pages 16, 19, and 24-26; subject item-level information
- Source positions/columns: 451-598, 801-954, 1601-1748, and 2001-2150
- Current mapping positions: mapped fields 134-136, 162-164, 186-188, and 202-204

#### Source fact

Reading and social studies use 44-byte item ranges. Mathematics and science use
42-byte item ranges, with source blank separators immediately after each range.

#### Current implementation

Each Reading range extends one byte into a source blank. Each Mathematics range
omits two bytes, and each Social Studies and Science range omits four bytes. The
Science reporting-category range is also named as strand numbers.

#### Impact

Item values can be truncated or can consume blank bytes, and the Science item
concept is mislabeled.

#### Proposed disposition

Correct all twelve ends and rename the Science reporting-category field after
independent verification.

#### Verification

Austin Perrin independently reviewed and confirmed all twelve range conflicts
and the incorrect Science concept name on 2026-09-25.

## Reviewed With No Findings

The archive and current official PDF match byte-for-byte. The omission of
previous-year history positions 2501-2841 agrees with the source overview,
which states that the entire section is blank because 2020 testing was
canceled. The omitted May-retest current-year history ranges also agree with
the source statement that only primary administrations occurred in 2021.

Apart from the findings above, mapped ranges reviewed against the source retain
their source positions. JSON values are strings, headers are unique, no header
exceeds 63 characters, and all seven filename regular expressions compile.
Administration metadata `0421` and `0521` agrees with the source.
