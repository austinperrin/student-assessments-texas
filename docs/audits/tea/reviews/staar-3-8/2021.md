### TEA-STAAR38-2021-010: Local and Agency Use rows use unsupported granularity

- Status: closed; independently verified 2026-10-15
- Severity: medium
- Reopened: 2026-10-15
- Source document: 2021 STAAR Grades 3-8 Reporting Student Data File Format
- Source page/table: page 8, Local Use and Agency Use
- Source positions/columns: 201-245, source rows 50-59

The source defines one four-byte Local Use field and one five-byte Agency Use
field for each subject. It does not define Agency Use A-E subfields. The
mapping omitted both Writing rows and divided each remaining five-byte Agency
Use row into five unsupported one-byte fields.

The remediation restores Local Use - Writing at positions 209-212 and Agency
Use - Writing at 231-235. It collapses the remaining Agency Use entries into
the five source-defined subject ranges at positions 221-245. Positions and
source-row ordinals are unchanged outside this section.
