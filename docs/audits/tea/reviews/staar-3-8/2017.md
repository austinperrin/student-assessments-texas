## Findings

### TEA-STAAR38-2017-001: Fourteen source fields are omitted

- Status: confirmed
- Severity: high
- Reviewer: Codex
- Verifier: Austin Perrin
- Disposition owner: Austin Perrin
- Target date: before audit closure
- Source document: 2017 STAAR Grades 3-8 Data File Format
- Source page/table: pages 5, 6, 8-11, and 22
- Current mapping positions: absent

#### Source fact

The source defines fields omitted by the mapping at:

- `107`: LEP Indicator Code
- `122`: Career and Technical Education Indicator Code
- `132-140`: Document Number
- `143`: Record Update Indicator
- `260`, `280`, `320`, and `340`: Language and Vocabulary Supports
- `261`, `281`, `299`, `321`, and `341`: Content Supports
- `1158-1161`: Year ELL Plan Determined

#### Current implementation and impact

Consumers cannot extract these documented identification, administration,
accommodation, and ELL-plan values.

#### Proposed disposition

Add all 14 fields with source-faithful headers and positions.

### TEA-STAAR38-2017-002: Twenty-three mappings occupy source-declared blank ranges

- Status: confirmed
- Severity: high
- Reviewer: Codex
- Verifier: Austin Perrin
- Disposition owner: Austin Perrin
- Target date: before audit closure
- Source document: 2017 STAAR Grades 3-8 Data File Format
- Source page/table: pages 6 and 8-11
- Current mapping positions: 23 mapped fields

#### Source fact

The source marks these affected bytes as `BLANK`:

- `165-189`
- `255`, `262-271`, `275`, `277-278`, and `282-291`
- `296`, `300-311`, `315`, `317-318`, and `322-331`
- `335`, `337-338`, and `342-350`

#### Current implementation and impact

The mapping assigns selected bytes in those ranges to foster care, class
group, oral administration, calculator, Content and Language Supports, ASL
video, spelling assistance, and auto text-to-speech concepts. These concepts
are not defined at those positions in the 2017 source.

#### Proposed disposition

Remove all 23 mappings that fall within documented blank ranges.

### TEA-STAAR38-2017-003: Most mapped fields omit column numbers

- Status: confirmed
- Severity: medium
- Reviewer: Codex
- Verifier: not required
- Disposition owner: Austin Perrin
- Target date: before family audit closure
- Source document: 2017 STAAR Grades 3-8 Data File Format
- Source page/table: pages 3-34
- Current mapping positions: 214 of 390 mapped fields

Repository rules require every mapped field to contain a string `column_num`
preserving source-row order and blank-row gaps. Two hundred fourteen fields
omit the property, and the remaining values do not consistently preserve
source ordinals. Recalculate all ordinals after field remediation.
