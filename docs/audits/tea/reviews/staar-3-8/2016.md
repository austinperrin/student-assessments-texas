## Findings

### TEA-STAAR38-2016-001: Twenty-two source fields are omitted

- Status: confirmed
- Severity: high
- Reviewer: Codex
- Verifier: Austin Perrin
- Disposition owner: Austin Perrin
- Target date: before audit closure
- Source document: 2016 STAAR Grades 3-8 Data File Format
- Source page/table: pages 5, 6, 9-14, 26, 36, and 37
- Current mapping positions: absent

#### Source fact

The source defines fields omitted by the mapping at:

- `107`, `122`, `132-140`, and `143`: student and administration fields
- `257`, `258`, `278`, `317`, `318`, and `338`: linguistic or standardized oral accommodations
- `361-363`: reading, mathematics, and writing online-test disruption flags
- `1158-1161`: Year ELL Plan Determined
- `2523`: previous-year reading primary STAAR Progress Measure
- `2591-2602`, `2605-2612`: seven fields in the previous-year reading June retest block

#### Current implementation and impact

Consumers cannot extract these documented identification, accommodation,
online-disruption, ELL-plan, or history values.

#### Proposed disposition

Add all 22 fields with source-faithful headers and positions.

### TEA-STAAR38-2016-002: Twenty-eight mappings occupy source-declared blank ranges

- Status: confirmed
- Severity: high
- Reviewer: Codex
- Verifier: Austin Perrin
- Disposition owner: Austin Perrin
- Target date: before audit closure
- Source document: 2016 STAAR Grades 3-8 Data File Format
- Source page/table: pages 6, 9-11, and 38
- Current mapping positions: 28 mapped fields

#### Source fact

The source marks the affected bytes as `BLANK`, including:

- selected bytes within `164-189`
- selected bytes within accommodation blanks `259-271`, `279-291`,
  `297-311`, `319-331`, and `339-350`
- six supposed grade-level Lexile ranges at `2901-2930`, which fall inside
  the source's `2825-3999` blank range

#### Current implementation and impact

The mapping assigns those bytes to foster care, class group, later-year
accommodation concepts, and six Lexile measures not defined by the 2016
source. Unexpected filler could therefore be reported as real values.

#### Proposed disposition

Remove all 28 mappings that fall within documented blank ranges.

### TEA-STAAR38-2016-003: Most mapped fields omit column numbers
