## Filename provenance and limitations

The 2025–2026 Interim layout describes a fixed-width reporting student data file but does not prescribe a delivered basename. The same-year `2025-2026-file-naming-convention.pdf` does not document a STAAR Interim data-file basename. No operational sample or delivered filename was available. Therefore the mapping does not add `filename_patterns`; introducing a regex would be unsupported by the available same-year evidence.

The audit validates the documented layout and source-supported filename evidence only. It does not validate an operational file instance because none was available.
