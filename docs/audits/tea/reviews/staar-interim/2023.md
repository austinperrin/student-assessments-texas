## Coverage and reconciliation

The complete layout was reviewed directly, including every named and blank
row, notes and code definitions, the test-code chart, and the terminal record
fields. The source contains 84 layout rows: 83 named rows represented in
`mapped_fields` and one intentionally omitted blank row at positions 486-505.
After correction, `column_num` preserves that omitted row as ordinal 43, so
`test_code` begins at ordinal 44 and `end_of_record` is ordinal 84.

The position ranges cover the full 1-2830 record without overlap when the
omitted blank row is included. The audit confirmed the widths and positions of
the demographic and accommodation fields; response and score segments;
probability, reporting-category, and historical indicators; four SE-alignment
segments; and overall score, performance, opportunity, attempt, and end-of-record
fields. Notes and code definitions remain distinct from field titles.

## Findings and resolutions

### 1. Blank-row ordinal was not preserved

- Severity: medium
- Source evidence: layout page 3, positions 486-505, width 20, field title
  `Blank`; `Test Code` follows at positions 506-508.
- Finding: the blank row was correctly omitted from `mapped_fields`, but the
  following `column_num` values did not preserve its source ordinal.
- Correction: incremented `column_num` for `test_code` through
  `end_of_record`, producing ordinals 44-84.
- Resolution: corrected and verified against all subsequent source rows.

### 2. Strength/weakness semantics were missing from headers

- Severity: medium
- Source evidence: layout pages 5-6, positions 796-837. The six current and
  six historical reporting-category fields are explicitly titled
  `Strength/Weakness Indicator` and have distinct value definitions.
- Finding: the prior headers ended at `reporting_category_N` or
  `historical_reporting_category_N`, obscuring the field's indicator meaning.
- Correction: renamed all twelve headers to include
  `_strength_weakness_indicator`.
- Resolution: corrected; raw-score fields at positions 784-795 remain
  separately named and mapped.

No other source-supported mapping corrections were found. The source directly
supports the existing identifier normalizations (`peims_id`,
`tx_unique_student_id`, and `local_student_id`) and the shared semantic
normalizations for the LEP and gifted/talented indicator fields.

## Filename provenance and limitations

The source identifies a fixed-width student results data-file layout, but it
does not publish a delivered basename or filename convention. The mapping has
no `filename_patterns`, and no unsupported pattern was added. No operational
sample or delivered filename was available, so filename matching and
sample-record parsing could not be validated.

Because the official URL currently returns 404, the archived PDF is the
authoritative evidence available for this review. No historical data was
reprocessed. Consumers using the old reporting-category header names will need
to adopt the corrected names before reprocessing this layout.
