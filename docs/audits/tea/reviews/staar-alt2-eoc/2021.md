## Findings And Resolutions

### ALT2-EOC-2021-001 - `column_num` offset after position 163

- Severity: medium
- Source evidence: PDF pages 4-8. Position 163 is source row 40, position
  164 immediately follows as source row 41, and the remaining positional rows
  continue through row 99 at position 2000.
- Finding: the mapping assigned position 164 to `column_num` 42 and retained a
  one-row offset through position 2000, despite no intervening source row.
- Resolution: decremented `column_num` for position 164 and every later named
  row. Position 2000 is now source row 99. Blank-row gaps remain intact.
- Final status: verified

### ALT2-EOC-2021-002 - shared concept headers were not normalized

- Severity: low
- Source evidence: PDF pages 3-4, positions 107, 117, and 157-162. The source
  defines the LEP/EL status indicator, Gifted/Talented participation indicator,
  and family-facing portal access code.
- Finding: the mapping used `lep_indicator_code`,
  `gifted_talented_indicator_code`, and
  `student_portal_unique_access_code` instead of the repository-required shared
  names for the same concepts.
- Resolution: changed the headers to
  `emergent_bilingual_indicator_code`,
  `gifted_and_talented_indicator_code`, and
  `family_portal_unique_access_code`. Ranges and source meanings are unchanged.
- Final status: verified
