- Current mapping positions: position 117, `column_num` 32

#### Source fact

The source identifies position 117 as `Gifted-Talented-Indicator-Code`, meaning
whether the student participates in a state-approved Gifted/Talented Program.

#### Current implementation

The mapping used `gifted_talented_indicator_code`, which preserved the meaning
but did not use the repository-required shared header.

#### Impact

One header changed. Positions, width, order, source meaning, and data values are
unchanged.

#### Proposed disposition

Use `gifted_and_talented_indicator_code`, the required shared normalization for
this source-supported concept.
