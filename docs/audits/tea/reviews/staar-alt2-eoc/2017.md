## Findings And Resolutions

### ALT2EOC-2017-001 — Shared concept headers used legacy names

- Severity: low
- Source evidence: page 4, position 107, identifies the LEP indicator and its
  current, monitored-exit, and non-LEP codes; page 5, positions 157–162,
  identifies the Student Portal unique access code and explains that it gives
  families confidential access to assessment results.
- Finding: `lep_indicator_code` and `student_portal_unique_access_code` used
  legacy header variants for concepts covered by the repository's required
  shared normalizations.
- Resolution: changed the headers to
  `emergent_bilingual_indicator_code` and
  `family_portal_unique_access_code`. Positions, lengths, and source ordinals
  were preserved.
- Final status: corrected; pending Reviewer 2 verification.

### ALT2EOC-2017-002 — Filename extensions contradicted the 2017 layout

- Severity: medium
- Source evidence: page 2 states twice that the delivered file extension is
  `.dat`, for both fixed-length and tab-delimited files.
- Finding: the inherited filename regexes permitted optional `.txt` suffixes
  or did not require the documented `.dat` suffix.
- Resolution: retained each inherited basename expression but made `.dat`
  mandatory and added the official 2017 layout to each pattern's references.
- Final status: corrected; pending Reviewer 2 verification.

### ALT2EOC-2017-003 — Official PDF URL used a stale TEA route

- Severity: low
- Reviewer 2 finding: the mapping and review record cited TEA's stale
  `/student-assessment/student-assessment-results/` route instead of the
  current `/data-reports/student-assessment-results/` route.
- Resolution: updated `metadata.pdf_url`, all same-year filename references,
  and this review record to the verified current URL. Reviewer 1 downloaded
  the current PDF and confirmed its SHA-256 is
  `af07a7fc252b17a8dba36e8250a57f5799fedafa77c1504e4213cf93b8982fac`,
  exactly matching the archived source.
- Final status: corrected; pending Reviewer 2 confirmation.
