## Findings And Resolutions

### R1-2019-01 — Normalize the LEP indicator concept

- Severity: low
- Source evidence: PDF page 3, position 107, `LEP-INDICATOR-CODE`; its codes describe current LEP status and four monitored years after exit.
- Finding: The header `lep_indicator_code` used a legacy term for the recurring emergent-bilingual status concept.
- Resolution: Changed it to the required shared normalization `emergent_bilingual_indicator_code` without changing the source meaning, position, or ordinal.
- Status: corrected and Reviewer 1 verified.

### R1-2019-02 — Normalize the gifted-and-talented indicator

- Severity: low
- Source evidence: PDF page 4, position 117, `GIFTED-TALENTED-INDICATOR-CODE`.
- Finding: The header omitted the conjunction required by the shared normalization rule.
- Resolution: Changed `gifted_talented_indicator_code` to `gifted_and_talented_indicator_code`.
- Status: corrected and Reviewer 1 verified.

### R1-2019-03 — Normalize the family portal access code

- Severity: low
- Source evidence: PDF page 4, positions 157-162, `STUDENT PORTAL UNIQUE ACCESS CODE`; the note says the code provides families confidential access to assessment results.
- Finding: The header used the legacy `student_portal_unique_access_code` variant.
- Resolution: Changed it to the required shared normalization `family_portal_unique_access_code`.
- Status: corrected and Reviewer 1 verified.
