## Findings And Resolutions

### ALT2-EOC-2016-001: official source URL was no longer canonical

- Severity: low
- Source evidence: TEA Data File Formats Archive, 2016, STAAR Alternate 2 EOC Assessments; official PDF pages 1-9.
- Observed mapping: `metadata.pdf_url` used a legacy TEA path.
- Correction: Updated `metadata.pdf_url` to the current official archive link.
- Resolution: corrected and verified; the current download and local archive have identical SHA-256 hashes.

### ALT2-EOC-2016-002: portal access-code header used a legacy normalization

- Severity: low
- Source evidence: PDF page 5, positions 157-162, `STUDENT PORTAL UNIQUE ACCESS CODE`; its note states that the code provides families confidential login access to assessment results.
- Observed mapping: `student_portal_unique_access_code`.
- Correction: Applied the repository-required normalization `family_portal_unique_access_code` without changing the source meaning.
- Resolution: corrected and verified.

### ALT2-EOC-2016-003: filename extensions contradicted same-year evidence

- Severity: medium
- Source evidence: PDF page 2 states that the fixed-length file and tab-delimited file extensions are `.dat`.
- Observed mapping: inherited patterns allowed `.txt`, omitted an extension, or did not require `.dat`.
- Correction: Preserved the inherited basenames but changed all four patterns to require `.dat`.
- Resolution: corrected and regex compilation verified. The basename provenance limitation remains because the same-year layout documents only the extension, not delivered basenames.
