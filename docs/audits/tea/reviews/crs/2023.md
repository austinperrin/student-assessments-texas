## Findings And Resolutions

### CRS-2023-001 — source ordinals compressed across blank rows

- Severity: high
- Source evidence: pages 3–8, positions 232–236, 247–250, 254–258,
  267–271, 291–295, 308–309, and 358–367 are seven separately printed
  blank rows.
- Finding: mapped `column_num` values after position 231 were sequential and
  did not preserve the source ordinals occupied by blank rows.
- Resolution: corrected all affected ordinals. Position 237 is now ordinal 16,
  position 251 is ordinal 27, position 259 is ordinal 31, position 272 is
  ordinal 40, position 296 is ordinal 43, position 310 is ordinal 50, position
  322 is ordinal 58, and position 368 is final source ordinal 60.
- Final status: corrected; pending independent verification.

### CRS-2023-002 — source qualifiers omitted from headers

- Severity: medium
- Source evidence: page 3 calls positions 188–202, 203–212, and 213
  “Student Last-Name,” “Student First Name,” and “Student Middle Initial.” Page
  5 calls position 259 “Special-Ed-Indicator-Code.” Pages 7–8 identify
  positions 318–321 as TELPAS/TELPAS Alternate proficiency ratings.
- Finding: the mapping omitted the student qualifiers, abbreviated special
  education in a way that did not preserve the complete concept, and omitted
  TELPAS Alternate from the four domain-rating headers.
- Resolution: renamed the fields to `student_last_name`, `student_first_name`,
  `student_middle_initial`, `special_education_indicator_code`, and four
  `telpas_and_telpas_alt_*_proficiency_rating` headers.
- Final status: corrected; pending independent verification.

### CRS-2023-003 — race field header added a term absent from the title

- Severity: low
- Source evidence: page 3 titles position 241
  “Native-Hawaiian-Pacific-Islander-Code.”
- Finding: the header included `other`, which occurs in the reporting-category
  note on page 4 but not in this field's title.
- Resolution: renamed it to `native_hawaiian_pacific_islander_code`.
- Final status: corrected; pending independent verification.
