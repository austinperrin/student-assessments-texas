## Findings and corrections

### CRS-2026-001 — Blank row was mapped as a nonexistent reporting category

- Severity: high
- Source evidence: PDF page 6 identifies positions 306–309 as `Blank5`, source
  ordinal 48. The source has reporting-category raw-score fields 1–5 only.
- Previous mapping: positions 306–307 were mapped as
  `reporting_category_6_raw_score`.
- Resolution: removed the unsupported field. The complete source reconciliation
  confirms all four positions are intentionally omitted.
- State: corrected; Reviewer 2 verification pending.

### CRS-2026-002 — Blank-row ordinal gaps were not preserved

- Severity: high
- Source evidence: PDF pages 3–10 contain seven separately printed blank rows.
- Previous mapping: downstream `column_num` values did not preserve these source
  ordinals; for example, position 237 was ordinal 15 rather than 16, and the
  final period was ordinal 55 rather than 59.
- Resolution: corrected every affected ordinal. The mapping now has 52 mapped
  names with gaps at source ordinals 15, 26, 30, 39, 42, 48, and 58.
- State: corrected; Reviewer 2 verification pending.

### CRS-2026-003 — Several headers dropped source qualifiers

- Severity: medium
- Source evidence: PDF page 3 labels the name fields `Student Last-Name`,
  `Student First-Name`, and `Student Middle-Initial`. Pages 7–9 label the five
  rating fields for both `TELPAS/TELPAS Alternate`.
- Resolution: added the `student_` qualifiers to the three name fields and
  preserved both assessment families in the composite and four proficiency
  rating headers. Required shared identifiers and concepts remain normalized,
  including `peims_id`, `local_student_id`, `tx_unique_student_id`,
  `emergent_bilingual_indicator_code`, and
  `gifted_and_talented_indicator_code`.
- State: corrected; Reviewer 2 verification pending.

### CRS-2026-004 — Official source URL was stale

- Severity: low
- Source evidence: TEA's current Data File Formats page links the 2026 layout at
  the `/data-reports/` URL recorded above. The prior `/student-assessment/` URL
  returns HTTP 404.
- Resolution: updated `metadata.pdf_url`; the current official download
  byte-matches the archive.
- State: corrected; Reviewer 2 verification pending.
