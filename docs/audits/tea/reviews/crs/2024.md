## Findings And Resolutions

### 1. Five omitted blank-row ordinals were not preserved

- State: `verified`
- Severity: high
- Evidence: pages 3-6, blank positions 232-236, 247-250, 254-258, 267-271, and 291-295.
- Source fact: these are distinct printed source rows before the two later blank rows whose gaps the original mapping already preserved.
- Resolution: shifted every affected `column_num` so all seven blank-row gaps are preserved. Position 237 is now ordinal 16, position 251 is ordinal 27, position 259 is ordinal 31, position 272 is ordinal 40, position 296 is ordinal 43, and position 513 is the final source ordinal 60.

### 2. Student-name qualifiers were omitted

- State: `verified`
- Severity: low
- Evidence: page 3, positions 188-213.
- Source fact: the titles are `Student Last-Name`, `Student First Name`, and `Student Middle Initial`.
- Resolution: renamed the headers to `student_last_name`, `student_first_name`, and `student_middle_initial`.

### 3. One race header added unsupported wording

- State: `verified`
- Severity: low
- Evidence: page 3, position 241.
- Source fact: the printed title is `Native-Hawaiian-Pacific-Islander-Code`; it does not include `Other`.
- Resolution: renamed the header to `native_hawaiian_pacific_islander_code`.

### 4. Four proficiency-rating headers omitted TELPAS Alternate applicability

- State: `verified`
- Severity: medium
- Evidence: pages 7-9, positions 347-466.
- Source fact: each title explicitly applies to `TELPAS/TELPAS Alternate`, and the notes separately define TELPAS and TELPAS Alternate values.
- Resolution: renamed the four headers to retain both programs, using `telpas_and_telpas_alternate_<domain>_proficiency_rating`.

The audit applied eight header corrections and corrected source ordinals for 39 mapped rows. Fixed-width ranges and values did not change. Existing shared normalizations are supported by the same-year source meanings, including `peims_id`, `local_student_id`, `tx_unique_student_id`, `emergent_bilingual_indicator_code`, and `gifted_and_talented_indicator_code`.
